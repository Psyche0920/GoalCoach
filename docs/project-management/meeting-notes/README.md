# Meeting notes

Create one Markdown file per decision-relevant meeting using `YYYY-MM-DD-topic.md`.

## Template

```markdown
# Meeting: <topic>

- Date/time:
- Attendees:
- Facilitator:
- Note taker:

## Objective

## Evidence reviewed

## Decisions

## Actions

| Action | Owner | Due date | Status |
|---|---|---|---|

## Open questions

## ADRs to create/update
```

Meeting notes capture context and actions. Permanent architecture decisions must also be copied into an ADR under `docs/decisions/`.
