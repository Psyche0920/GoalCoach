# GoalCoach — Vector Database (ChromaDB) Engineering Specification & Progress                                                                                                                                         
                                                                                                                                                                                                                        
This document serves as the canonical technical specification, architectural guide, and operational log for the ChromaDB vector retrieval layer within GoalCoach.                                                     
                                                                                                                                                                                                                        
---                                                                                                                                                                                                                   
                                                                                                                                                                                                                        
## 1. Architectural Role & Context Boundary                                                                                                                                                                           
                                                                                                                                                                                                                        
GoalCoach applies a **Hybrid Retrieval Architecture** to prevent over-agentification and LLM hallucinations:                                                                                                          
                                                                                                                                                                                                                        
* **SQLite (`data/database1/goalcoach.db`)**: The deterministic single source of truth.                                                                                                                               
    * Stores dynamic learner state: mastery scores, retention probabilities, review schedules, error logs, and session history.                                                                                         
    * Stores relational curriculum definitions: `curriculum_concepts`, `teaching_cards`, and `exercises`.                                                                                                               
* **ChromaDB (`data/database2/chroma_db`)**: The auxiliary semantic vector retrieval layer.                                                                                                                           
    * Stores unstructured HSK learning materials: grammar explanations, communicative goals, syntactic patterns, and dialogue examples.                                                                                 
    * Resolves vague, unlabelled, or semantic learning errors where the exact concept key is unknown.                                                                                                                   
* **Feature Flag Guard**: Vector retrieval is optional and gated behind `Settings.enable_vector_retrieval` (disabled by default per proposal risk mitigations).

## 2. Technical Foundations                                                                                                                                                                                           
                                                                                                                                                                                                                        
### Embedding Models & Vector Mathematics                                                                                                                                                                             
* **Model**: `BAAI/bge-small-zh-v1.5` running locally via `sentence-transformers` (~300MB RAM, 512-dimensional dense embeddings).                                                                                     
* **Distance Metric**: Cosine Distance ($1 - \text{Cosine Similarity}$). Lower values indicate closer semantic similarity.                                                                                            
* **Confidence Mapping**: `relevance_confidence = round(max(0.0, 1.0 - distance_score), 4)`.

## 3. Core Components & Code Layout                                                                                                                                                                                   
                                                                                                                                                                                                                        
### Key Files                                                                                                                                                                                                         
* `src/goalcoach/infrastructure/retrieval/chunk_factory.py`: `CardChunkFactory` with token bounds (≤300 tokens) and sentence-safe truncation.                                                                         
* `src/goalcoach/infrastructure/retrieval/chroma_service.py`: `ChromaService` managing local ChromaDB queries and emitting typed `RetrievedCardPayload` instances.                                                    
* `src/goalcoach/agents/retrieval.py`: `RetrievalAgent` implementing dual-route dispatch (SQL-first, ChromaDB-fallback gated by `Settings`).                                                                          
* `scripts/vector_store.py`: Ingestion manager to extract curriculum from SQLite and upsert chunks to ChromaDB.                                                                                                       
* `scripts/observer.py`: File watcher daemon monitoring `data/database1/` to trigger automated syncs during local development.

### 2.
