# Proposal source documents

This directory contains the original project proposal and external review material. Treat these PDFs as read-only project inputs.

## Precedence

1. `GoalCoach_Proposal_Final.pdf` defines the product concept and proposed agentic system.
2. `GoalCoach_Proposal_und_Senior_AI_Review_EN_260829.pdf` is the primary engineering blueprint and four-week feasibility review.
3. `GoalCoach_Supplementary_Feedback_EN_ZH_Mirror.pdf` clarifies later implementation ambiguities, including HSK1 MVP scope, planning cadence, SQL-first retrieval, and optional LangGraph/ChromaDB.

Derived architecture is documented in [`../docs/architecture/`](../docs/architecture/), and changes to consequential decisions must be recorded in [`../docs/decisions/`](../docs/decisions/). Do not edit the PDFs to represent later decisions.
